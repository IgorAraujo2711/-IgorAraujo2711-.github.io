# PetAmigo Petshop (Fase 1)

Sistema web (front-end) de um petshop, desenvolvido para a disciplina Fundamentos de Sistema Web. Usa apenas HTML, sem CSS e sem JavaScript.

## Páginas
- `index.html`: apresentação do petshop e links para as seções.
- `acessorios.html`: 2 produtos (foto, descrição e valor).
- `racoes.html`: 2 produtos (foto, descrição e valor).
- `higiene.html`: 2 produtos (foto, descrição e valor).
- `servicos.html`: banho, tosa e banho e tosa, com descrição e valor, com ou sem tele-busca.
- `contato.html`: endereço, telefone, e-mail e horário.

## Funcionalidades
- Cabeçalho com nome, informações do petshop e menu de navegação em todas as páginas.
- Rodapé com contato, links de navegação e autoria em todas as páginas.
- Navegação entre páginas por links.

## Publicação
Repositório GitHub > Settings > Pages > Branch `main`, pasta `/ (root)`.
